# BombiTeclado

Teclado braille de pantalla para Android 12 o posterior. Cada punto se escribe donde se apoya el dedo. Funciona con varios lectores de pantalla y está probado con JieShuo, TalkBack y Backtalk.

La guía, con todos los gestos, y la política de privacidad están en [teclado.aelbak.dev](https://teclado.aelbak.dev).

Este repositorio solo guarda las versiones publicadas.

## Instalar

1. Descargar [bombiteclado.apk](https://github.com/AAyoubelbakhti/bombiteclado-releases/releases/latest/download/bombiteclado.apk). El enlace da siempre la última versión.
2. Abrirlo en el móvil. Si Android lo pide, permitir instalar apps desde esa fuente.
3. Abrir BombiTeclado: la bienvenida guía la activación y la elección del teclado.

Desde la 0.6.0, la app no se actualiza sola: cada versión nueva se descarga desde aquí. Las versiones anteriores la encuentran solas y la instalan.

## English

BombiTeclado is an on-screen braille keyboard for Android 12 and later. Each dot is typed where a finger rests. It works with several screen readers and has been tested with JieShuo, TalkBack and Backtalk.

The guide, with every gesture, and the privacy policy are at [teclado.aelbak.dev](https://teclado.aelbak.dev).

This repository only holds the published versions. Download [bombiteclado.apk](https://github.com/AAyoubelbakhti/bombiteclado-releases/releases/latest/download/bombiteclado.apk), which always gives the latest version, open it on the phone and follow the welcome screens. From 0.6.0, the app does not update itself: each new version is downloaded from here. Earlier versions find it on their own and install it.

BombiTeclado uses liblouis 3.39.0, unmodified, and its tables, under the LGPL 2.1 or later. Its source code is at [liblouis 3.39.0](https://github.com/liblouis/liblouis/releases/tag/v3.39.0). The TalkBack sound theme uses the TalkBack sounds, under the Apache 2.0 license. The app shows every license in Help, Licenses.
